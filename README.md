# 💫 About Me
I'm a data analyst with a strong computer science background and a passion for turning raw, messy data into clear insights that drive decisions. I enjoy the full analysis workflow: collecting and cleaning data, exploring it, uncovering patterns, building visualizations, and communicating findings in a way that both technical and non-technical people can act on.

My machine learning background lets me go beyond descriptive analysis into predictive modeling, and I'm especially interested in how AI and LLMs can speed up analytics and make insights more accessible.

- 🔍 Exploratory data analysis, data cleaning, and statistical analysis
- 📈 Data visualization and storytelling with data
- 🤖 Predictive modeling and applied machine learning
- 🧠 Exploring LLM-powered and agentic tools for analytics automation
- 🌱 Currently deepening my skills in SQL, dashboards, and MLOps

# 🔄 How I Work
```
Ask the right question → Collect & clean data → Explore & analyze → Visualize → Recommend & communicate
```
